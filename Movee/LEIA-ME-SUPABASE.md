# Movee — pacote Supabase para GitHub

Este ZIP contém o banco correspondente ao código de `Movee-site-GitHub.zip`: 20 scripts de produção, SQL consolidado, banco por extenso, documentação, consulta administrativa e testes separados.

Extraia os dois ZIPs no mesmo destino para unir a pasta `Movee`, leia `ORDEM-DO-BANCO.md` e siga `docs/GITHUB.md`. A instalação nova usa os scripts 01–20 **ou** o consolidado, sem duplicar a execução. RLS, permissões, Storage privado e triggers fazem parte da sequência.
